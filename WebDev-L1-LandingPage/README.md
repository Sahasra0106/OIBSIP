# StudyNest – Student Productivity Landing Page

## 📌 Project Overview

StudyNest is a modern and responsive landing page designed for a fictional student productivity platform. It aims to help students organize their study schedules, manage time, and track their academic goals.

This project was developed as part of the **Oasis Infobyte Web Development Internship – Level 1, Task 1**.

## 🚀 Features

- Sticky navigation bar with smooth scrolling.
- Attractive hero section with a call-to-action button.
- Daily goals dashboard card.
- Features section with three feature cards.
- About section describing the platform.
- Testimonials section with sample reviews.
- Footer with contact and social media links.
- Responsive layout for desktop and mobile devices.
- Hover effects and consistent purple colour theme.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, Flexbox, Grid and responsive design.

## 💻 How to Run the Project

1. Clone or download the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the StudyNest landing page in your browser.

## 🎨 Design Theme

The website uses a purple, lavender and white colour palette to create a clean, modern and student-friendly appearance.

## 📱 Responsive Design

The layout uses CSS Flexbox, CSS Grid and media queries to adapt to different screen sizes, including desktops, tablets and mobile devices.
